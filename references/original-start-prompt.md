# 文献精读新对话启动提示词

请完整处理本次提供的论文正文与 Supporting Information，最终制作可直接放入 Obsidian 文献文件夹的完整成品。

## 一、附件角色

### 1. 执行规范

`01_PDF读取与全流程执行说明书.md`

负责源文件识别、PDF分段读取至 EOF、截断续读、OCR与视觉核验、内部台账、图片提取、写作许可门和最终验收。

### 2. 成稿规范

`文献精读笔记格式模板.md`

负责最终笔记的分析范围、逻辑结构、实验拆分、证据审查、逐图导读、统计与偏倚审查、字数和完整度。

### 3. 质量标尺

- `03_优秀成稿范例_A_仅作结构深度标尺.md`
- `04_优秀成稿范例_B_仅作结构深度标尺.md`

两份范例只用于校准阶段叙事、实验拆分粒度、分析密度、逐图导读和整体篇幅。不得从范例中提取、迁移或混入任何论文事实、实验内容、数值、判断、图片信息或句子。

### 4. 本次事实来源

本次上传的论文正文、Supporting Information 及与该论文直接配套的源文件，是最终成稿的事实来源。

不得根据文件名猜测 PDF 身份。必须依据题目、作者、DOI、期刊信息和正文内容确认正文与 SI 的对应关系。

## 二、执行顺序

1. 将执行说明书、成稿模板和两份范例从头到尾完整读取至 EOF。
2. 盘点全部源文件，确认正文、SI、文件版本和对应关系。
3. 按照执行说明书将每个 PDF 分段读取至 EOF。
4. 工具输出发生截断时，自动缩小读取范围，从最后确认完整的位置续读，直至覆盖最后一页。
5. 建立页面、Figure、实验、分组、方法、命题、推进和 SI 承重证据台账。
6. 按真实科学问题建立全文阶段、主线、支线与证据地图。
7. 通过执行说明书中的写作许可门后，才允许开始最终成稿。
8. 提取并核验全部主图、Scheme 和补充 Figure，将图片放入对应论证阶段。
9. 完成页面、事实、Figure、SI、成稿内容、图文链接、Source 与目录的反向验收。
10. 随机抽取至少三个证据阶段，与两份优秀范例对照；明显更薄时自行返工。
11. 一次性交付最终文件夹，不交付中间稿。

## 三、禁止提前写作

在执行说明书规定的写作许可门通过前，不得开始最终正文。

不得采用以下做法：

- 先按摘要和主图写一版，再补 Methods 和 SI；
- 先交付部分章节、内容骨架或未验收初稿；
- 用 Figure 顺序代替真实科学问题与证据推进；
- 因篇幅过长而合并不同判别任务的实验；
- 因某项证据位于 SI 而降低分析深度；
- 只对主图做逐面板证据表，却将 Figure S 压缩成图片后的一句话摘要；
- 用图片导读、面板表、take-home message 或阶段性评价替代逐实验设计与证据分析正文；
- 仅使全文总字数达标，却让某个包含多项承重实验的核心阶段只有数百字分析；
- 在灵感部分用少数几个紧凑段落一次性概括多个独立构思转折，而没有按“一个灵感点、一个单独小节或完整段落”展开；
- 核心阶段没有形成“为何必须做—怎样设计—得到什么—能说明什么—为何仍然不够—下一步如何出现”的证据递进；问题清单可以使用但不强制，不得把这一逻辑节奏机械化为固定标题填空；
- 为满足Callout、问题卡或槽位数量而切碎论证、缩短篇幅；重点词汇、设计冲突和阶段结构以模板中的正向示范为准，不另行机械计数；
- 设置一级、二级或三级标题后不提供与标题直接对应的实质正文，或者只用一句话、表格、图片、链接、图注复述或通用套话敷衍该标题；不适用的标题必须删除；
- 阶段仅有一段总述，随后直接连续嵌入多张 Figure/Figure S，使读者看不到问题之间的层层递进；
- 将文件齐全、章节齐全或目录洁净误当作内容完成。

## 四、最高优先级

发生冲突时，按照以下顺序处理：

```text
事实准确与证据忠实
→ 分析深度
→ 逻辑闭合
→ 内容完整度
→ 可读性
→ 具体格式
```

如果模板中的具体标题名称、占位句式或非承重装饰与论文的真实论证发生冲突，可以调整。但阶段“一项独立科学问题—一个可见回答单元—相关证据就地出现—残余缺口引出下一问题”的结构属于逻辑骨架，不属于可放弃的具体格式。不得以“灵活变通”为由把多个证据升级重新压进长段落。

## 五、最终交付

最终目录为：

```text
YY.MM.DD-论文中文题目/
├── 设计思路与证据审查.md
├── Figure/
└── Source/
```

最终成稿必须达到 `文献精读笔记格式模板.md` 规定的分析深度、逻辑、完整度和字数要求。

最终目录中不得出现 OCR 文本、PDF 渲染页、脚本、日志、内部台账、缓存、contact sheet 或其他临时文件。

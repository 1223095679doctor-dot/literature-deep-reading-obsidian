# 范例级质量量表

本量表提炼自两份优秀成稿的共同阅读体验。它校准“感觉”和分析密度，不提供任何新论文事实。

## 目录

1. 成品应给人的感觉
2. 两份范例的互补优势与融合原则
3. 阶段级评分
4. 实验级评分
5. 图级评分
6. 批判与启发评分
7. 返工触发器

## 1. 成品应给人的感觉

读者不必回到原文，也能回答：作者为什么想到这个方案、每一步为什么必须出现、具体对照排除了什么、数据真正建立了什么、机制在哪个箭头处仍脆弱，以及下一项最有判别力的实验是什么。

目录本身应展示证据升级，而不是只展示论文主题或 Figure 编号。正文以连续论证为主体，表格、Callout 和图片只是导航与稳定比较工具。

## 2. 两份范例的互补优势与融合原则

范例 A 的主要优势是全局覆盖和系统审计：名词前置、材料/机制模块拆解、长链阶段推进、全部主图与 SI 覆盖、统计透明度、钢人/红队、临床外推和后续研究路线形成完整闭环。

范例 B 的主要优势是单阶段内部的原子化分析：先提出判别问题，再解释实验安排、对照逻辑、实际观察、作者归因、隐藏前提、阶段性批判、最有判别力的实验和可迁移原则。它更强调把一项复杂 Figure 拆成多个证据任务。

融合模板吸收两者优点：

- 用范例 A 的“全文地图和完整覆盖”防止漏掉支线、SI、统计与外推；
- 用范例 B 的“阶段内部原子化”防止只有宏观总述、表格和堆图；
- 用融合模板统一最终章节，避免照抄任一范例的历史编号；
- 对简单阶段不机械复制九个小节，对复杂承重阶段则不得以灵活为由合并证据升级；
- 分析密度取两份范例中与当前证据复杂度更接近者作为下限，而不是平均后稀释。

### 沉浸式阶段入口

优秀阶段不应让读者一上来就接收一串实验结果。阶段标题之后先用 Callout 带读者依次经历：

```text
作者怎样发现/定位这个问题
→ 为什么现有证据还不够
→ 怎样把问题转成实验方案
→ 方案依赖什么前提
→ 成功、失败和竞争解释各会看到什么
→ 本阶段准备把证据推进到哪一层
```

这些是认知任务，不是固定标题。每个 Callout 应有当前论文特异的标题和完整回答段落。读者看完入口后，应能在尚不知道实际结果时预测作者为什么选择这些实验以及怎样判定成败。

真实试跑表明，仅在阶段开头放三四个 Callout 仍可能产生“板块齐全但层层分析不足”。阶段整体还必须呈现以下证据节奏：

```text
必须回答的问题/上一缺口
→ 每项实验分别承担什么任务
→ 设计与报告是否完整
→ 成功与失败各会看到什么
→ Figure 就地进入并逐面板解释
→ 实际观察（不写机制）
→ 作者怎样归因
→ 隐藏前提与推理跳跃
→ 阶段性评价
→ 最有判别力的实验
→ 下一阶段为什么出现
```

Callout 数量不是质量指标。标题、段落、表格和 Callout 应共同完成上述功能；复杂阶段不得合并，简单阶段可以合并相邻功能。

### 灵感与实验路线的边界

灵感部分回答“作者为什么会构造这个方案”，证据阶段回答“作者怎样验证它”。灵感来源可以是临床矛盾、领域已有关系、作者可调用的材料/技术模块、两个知识系统的可组合性或一个待兼顾的设计冲突。后文实验结果只能用于审查灵感是否成立，不能反过来冒充灵感来源。

### Figure 就地整合与逐面板导读

先帮助读者看懂图，再审查图。为避免两张表割裂阅读，可使用一张逐面板完整分析表同时承载基础层和分析层：

1. 每张大图单独写明 Figure/Scheme/Figure S 名称并就地嵌入阶段；
2. 表格逐行介绍 a、b、c 的基本图注、对象/组别、直接观察、故事任务、支持和边界；
3. take-home message 汇总证据升级与边界。

只有分析层而没有基础层，会让回看笔记的读者忘记面板内容；只有基础层则退化为图注翻译。

禁止把全部图片抽离阶段后集中放进“逐图与 SI 证据审查”。这会迫使读者在思路和图片之间来回跳转，也容易造成前文只讲抽象结论、后文重复图注。图片必须出现在其证据任务发生的位置。

## 3. 阶段级评分（每项 0–2）

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 入口缺口 | 无缘由开始实验 | 有背景但缺判别问题 | 明确上一证据为何不够及当前判定标准 |
| 实验拆分 | 多项实验合并概括 | 按图或方法粗拆 | 按独立自变量、对照任务和证据性质拆分 |
| 证据递进 | “进一步验证”串联 | 大致有先后 | 每组实验写清解决项、残余缺口和下一步由来 |
| 观察与归因 | 混写 | 偶尔区分 | 数据、作者解释和审查上限稳定区分 |
| 定量密度 | 仅“显著” | 部分数字 | 关键组别、n、方向、效应量/P/CI 尽可能完整 |
| 阶段边界 | 无 | 泛泛局限 | 对具体命题说明支持上限、替代解释和分叉实验 |
| 阶段厚度 | 被表格和图片替代 | 有正文但过薄 | 多项承重实验有足够独立正文，复杂阶段约 3k–4k+ 中文字符 |

核心阶段低于 11/14 分必须返工；任何“入口缺口、证据递进、观察与归因”为 0 都是阻断项。

## 4. 实验级评分（每项必须可回答）

- 为什么在此处做，而不是仅“作者随后检测”？
- 对象、处理、剂量、时序和唯一变化是什么？
- 对照承担哪一个判别任务？仍存何种混杂？
- 读出实际测量什么？不能单独证明什么？
- 实际观察及统计单位是什么？
- 作者怎样解释？数据最多支持到哪一层？
- 若替代解释成立，会出现什么不同模式？
- 哪项后续实验最能改变当前判断？

缺少前三项时，不能把该实验视为已分析。

## 5. 图级评分

每张含数据的 Figure/Figure S：

- 位于它真正服务的证据小节；
- 完整图像可读且 panel 齐全；
- 有整图定位；
- 五列表覆盖所有面板或合理面板组；
- 表中“故事任务”说明证据升级，而非复述测量方法；
- “可以支持”与“不能单独支持”形成边界；
- 独立 take-home message 同时包含建立与未建立；
- 补图深度不因位于 SI 而降级。

任何已嵌入数据图缺少五列表或 take-home message 都是阻断项。

## 6. 批判与启发评分

高质量批判必须绑定命题、证据和可测预测。优先寻找：因果方向、时间顺序、暴露或剂量差异、模块物性变化、测量偏差、模型自然恢复、共同上游、伪重复、选择性报告和外推越界。

高质量启发不是“换材料、加组学、做临床”，而是：

```text
具体缺口 → 可证伪假设 → 相对原文的唯一增量
→ 对象/组别/时序/读出 → 结果 A/B 的判别意义 → 失败原因
```

先钢人后红队。即使主机制失败，也要识别仍成立的最小真实贡献。

## 7. 返工触发器

出现任一项即返工：

- 删除 Figure 编号后，正文无法解释实验为什么这样推进；
- 某核心阶段一段总述后连续堆图；
- 三种以上不同证据性质压在一两个长段落；
- 关键对照只被列出，没有解释唯一变化和残余混杂；
- SI 承重证据仅进入图表索引或一句话摘要；
- 全文总字数足够，但任一复杂核心阶段明显过薄；
- 钢人只是赞美，红队只是零散挑错；
- 后续实验无组别、时序、控制变量或判别预测；
- 标题下只有一句话、表格、图片、链接或通用套话。

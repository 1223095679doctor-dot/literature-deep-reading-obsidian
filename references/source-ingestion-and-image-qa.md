# 源文件读取、原图核对与目录验收（活动规则）

本文件只规定取证、读取、原图核对与目录验收，不规定成稿字数、阶段数量、可见栏目或逐图句式。

## 1. 确认来源身份

- 盘点用户提供的正文、Supporting Information、数据附件和其他配套文件。
- 依据题目、作者、DOI、期刊、年份和正文内容确认对应关系，不根据文件名猜测。
- 记录文件页数、版本及无法获得的外部附件；不得把未提供材料假装成已读取。
- 身份核实后建立归档映射：主论文PDF → `Source/正文.pdf`；Supporting Information或Supplementary Materials主PDF → `Source/补充材料.pdf`。这里的“正文/补充材料”是最终标准文件名，不沿用出版社下载串名，也不使用`原文.pdf`、`main.pdf`、`supp.pdf`等同义名称。
- reporting summary、editorial checklist、peer-review file、source data和数据表不等于论文补充材料，不能占用`补充材料.pdf`。存在多个真正独立的补充PDF时，以包含主要Supplementary Methods/Figures/Tables者命名为`补充材料.pdf`，其余依次为`补充材料-2.pdf`、`补充材料-3.pdf`并记录内容范围；其他附件保留清楚的描述性名称。

### 新项目必须立即落盘

来源身份核实后、任何Figure草稿开始前，必须以本地日期和准确中文题目建立`YY.MM.DD-准确的论文中文题目/Source/`，并把用户提供且本次实际读取的正文、主补充PDF复制为`正文.pdf`与`补充材料.pdf`。这是逐图任务的启动门，不得等全文读完或最终合并时才补建，也不得只留下英文短标识的`_figure_drafts/`目录。复制归档不改变用户原始文件。

即使用户当轮只要求“先做第一张Figure”，也执行同样的初始化。单图草稿使用与总目录一致的日期题目，放在同级`_figure_drafts/YY.MM.DD-准确的论文中文题目/`；最终总目录在逐图阶段只容纳已核实的Source，不放`gate-status.json`、单图草稿或空白主笔记。

## 2. 全量读取至 EOF

- 正文、SI 和承重附件必须从首页读到最后一页。
- 工具输出被截断时，缩小页段并从最后一个确认完整的位置重叠续读。
- 可选文本 PDF 优先提取文本；扫描页再 OCR。公式、复杂表格、显微图、跨页图注和 OCR 可疑处必须回看页面图像。
- 写作前建立内部台账：页面、Figure/面板、实验对象与分组、方法、关键结果、统计、legend、对应Results、承重SI，以及“每个补图面板直接支撑哪个主图命题/应插入何处”的依赖关系。台账不进入最终目录。

## 3. 写作许可门

只有在以下条件同时满足后才能开始成稿：

- 所有来源读至 EOF；
- 全部主图、Scheme、正式 Table 和 Figure S 已入账；
- 每张 Figure 已汇集完整 legend、相关 Results、必要 Methods 和承重 SI；
- 主图与Figure S的逻辑依赖地图已完成，不能仅按图号列清单；
- 正文与 SI 的身份和版本对应关系已确认；
- 无法辨认、缺页、外部附件缺失等异常已经查明并记录。

禁止先按摘要或主图写一版，再补 Methods 和 SI。

## 4. 原图核对，不截图交付

- 原始PDF页面或原始附件中的Scheme、主图和Figure S必须逐张查看；不能只依赖OCR文本、legend或Results写稿。
- 对每张Figure核对面板范围、字母标签、坐标轴、图例、颜色、比例尺、统计标记、注释符号和跨页面板，并把关键干预、分组和读出写进内部台账。无法辨认的文字列为异常，不得猜测。
- 默认成品不包含论文图片：不截图、不整页渲染、不裁切、不导出PDF内嵌对象、不拼接跨页图，也不创建`Figure/`目录或在Markdown中加入图片链接。
- 用户明确要求插图时，图片处理属于额外任务，按当次要求执行；是否插图不影响本skill默认的逐Figure教学与门禁。
- “不插图”只取消交付层面的图像制作，不取消读图：每个观察、方向和视觉元素仍须能回到原始PDF页面或附件核对。

## 取证完整与教学取舍分开

样本量、统计方法、剂量、时间、操作与来源冲突仍须内部核实，不因用户不需要统计课而少读来源。完整legend仍须忠实翻译，但按面板拆分并默认展开地放在对应陪读之前；跨面板共用条件在首个相关面板前完整翻译，统一统计尾注可在相关面板组结束后折叠。正式表仍完整翻译并按需要折叠查阅。教学主线展开理解当前干预、分组、检测方法和结果意义所需的信息；每种方法讲清测量对象、基本原理、选择理由与原图读法，但不写操作SOP。常规统计与系统性局限集中到同一主笔记末尾，不让审计细节打断逐图阅读。

## 5. 项目目录与最终来源保留

默认最终目录只允许：

```text
YY.MM.DD-论文中文题目/
├── 作者思路与实验设计带读.md
└── Source/
    ├── 正文.pdf
    └── 补充材料.pdf
```

`Source/` 保存本次实际读取的原始文件内容；归档复制不会改写PDF内部内容，但正文与主补充PDF的文件名必须分别为`正文.pdf`和`补充材料.pdf`。完成前同时核对文件名和文件身份，发现下载串名、`原文.pdf`或把reporting summary误作补充材料均须返工。默认最终目录不得出现截图、裁图、OCR、渲染页、脚本、日志、台账、缓存或 contact sheet。

这个目录在项目开始时创建并贯穿整个逐图过程；“最终目录”只表示最终清理后的内容形态，不表示可以到全文结束才创建。第一张Figure交付时必须同时确认总目录已存在、Source已按标准名称归档、草稿位于总目录外。

完整任务验收须确认`作者思路与实验设计带读.md`存在且有实质内容，包含读前地图、按科学依赖排列的逐Figure主体、检测方法讲解、证据边界与全文迁移收束，并能脱离原文首次通读。最终目录不得保留旧版两份Markdown。

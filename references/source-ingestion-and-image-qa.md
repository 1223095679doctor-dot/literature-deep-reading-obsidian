# 源文件读取与图片验收（活动规则）

本文件只规定取证、读取、图片与目录验收，不规定成稿字数、阶段数量、可见栏目或逐图句式。

## 1. 确认来源身份

- 盘点用户提供的正文、Supporting Information、数据附件和其他配套文件。
- 依据题目、作者、DOI、期刊、年份和正文内容确认对应关系，不根据文件名猜测。
- 记录文件页数、版本及无法获得的外部附件；不得把未提供材料假装成已读取。

## 2. 全量读取至 EOF

- 正文、SI 和承重附件必须从首页读到最后一页。
- 工具输出被截断时，缩小页段并从最后一个确认完整的位置重叠续读。
- 可选文本 PDF 优先提取文本；扫描页再 OCR。公式、复杂表格、显微图、跨页图注和 OCR 可疑处必须回看页面图像。
- 写作前建立内部台账：页面、Figure/面板、实验对象与分组、方法、关键结果、统计、legend、对应 Results、承重 SI。台账不进入最终目录。

## 3. 写作许可门

只有在以下条件同时满足后才能开始成稿：

- 所有来源读至 EOF；
- 全部主图、Scheme、正式 Table 和 Figure S 已入账；
- 每张 Figure 已汇集完整 legend、相关 Results、必要 Methods 和承重 SI；
- 正文与 SI 的身份和版本对应关系已确认；
- 无法辨认、缺页、外部附件缺失等异常已经查明并记录。

禁止先按摘要或主图写一版，再补 Methods 和 SI。

## 4. 图片提取

- 提取全部主图、Scheme 和 Figure S；优先原始对象，不可靠时使用约 300 dpi 页面渲染。
- 图片必须完整保留面板标签、全部子图、坐标轴、图例、比例尺、统计标记、注释符号及跨页面板。
- 裁切边界不确定、图注跨页或面板范围难以确认时，宁可保留更大范围或完整页面，不得为了美观裁掉信息。
- 合并跨页图时保持阅读顺序，并确认没有重复、缺缝或缩放到不可读。

## 5. 双向视觉验收

对每张最终图片执行：

1. 根据原始 legend 核对其应含的面板范围；
2. 将最终 PNG 与原始 PDF 页面并排查看；
3. 检查标签、图例、坐标、比例尺、统计标记和边缘内容；
4. 从笔记中的 Figure 链接与逐子图 Callout 反查图片；
5. 从 Figure 文件反查笔记，确认没有漏图或孤立图片。
6. 为每张最终图片盘点全部可见文字，并确认笔记中存在对应解释；高分辨率下仍无法辨认的文字列为异常，不得自行猜测。

文件存在、链接有效、图像内容完整是三个独立验收项。脚本不能代替逐张视觉核验。

## 6. 最终目录与来源保留

最终目录只允许：

```text
YY.MM.DD-论文中文题目/
├── 设计思路与证据审查.md
├── Figure/
└── Source/
```

`Source/` 保存本次实际读取的原始正文和补充材料。最终目录不得出现 OCR、渲染页、脚本、日志、台账、缓存或 contact sheet。

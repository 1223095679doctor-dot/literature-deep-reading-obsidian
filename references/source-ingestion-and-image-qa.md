# 源文件读取与图片验收（活动规则）

本文件只规定取证、读取、图片与目录验收，不规定成稿字数、阶段数量、可见栏目或逐图句式。

## 1. 确认来源身份

- 盘点用户提供的正文、Supporting Information、数据附件和其他配套文件。
- 依据题目、作者、DOI、期刊、年份和正文内容确认对应关系，不根据文件名猜测。
- 记录文件页数、版本及无法获得的外部附件；不得把未提供材料假装成已读取。
- 身份核实后建立归档映射：主论文PDF → `Source/正文.pdf`；Supporting Information或Supplementary Materials主PDF → `Source/补充材料.pdf`。这里的“正文/补充材料”是最终标准文件名，不沿用出版社下载串名，也不使用`原文.pdf`、`main.pdf`、`supp.pdf`等同义名称。
- reporting summary、editorial checklist、peer-review file、source data和数据表不等于论文补充材料，不能占用`补充材料.pdf`。存在多个真正独立的补充PDF时，以包含主要Supplementary Methods/Figures/Tables者命名为`补充材料.pdf`，其余依次为`补充材料-2.pdf`、`补充材料-3.pdf`并记录内容范围；其他附件保留清楚的描述性名称。

## 2. 全量读取至 EOF

- 正文、SI 和承重附件必须从首页读到最后一页。
- 工具输出被截断时，缩小页段并从最后一个确认完整的位置重叠续读。
- 可选文本 PDF 优先提取文本；扫描页再 OCR。公式、复杂表格、显微图、跨页图注和 OCR 可疑处必须回看页面图像。
- 写作前建立内部台账：页面、Figure/面板、实验对象与分组、方法、关键结果、统计、legend、对应Results、承重SI，以及“每个补图面板直接支撑哪个主图命题/应插入何处”的依赖关系。台账不进入最终目录。

## 3. 写作许可门

只有在以下条件同时满足后才能开始成稿：

- 所有来源读至 EOF；
- 全部主图、Scheme、正式 Table 和 Figure S 已入账；
- 每张 Figure 已汇集完整 legend、相关 Results、必要 Methods 和承重 SI；
- 主图与Figure S的逻辑依赖地图已完成，不能仅按图号列清单；
- 正文与 SI 的身份和版本对应关系已确认；
- 无法辨认、缺页、外部附件缺失等异常已经查明并记录。

禁止先按摘要或主图写一版，再补 Methods 和 SI。

## 4. 图片提取

- 提取全部主图、Scheme 和 Figure S；优先原始对象，不可靠时使用约 300 dpi 页面渲染。
- 图片必须完整保留面板标签、全部子图、坐标轴、图例、比例尺、统计标记、注释符号及跨页面板。
- 裁切边界不确定、图注跨页或面板范围难以确认时，宁可保留更大范围或完整页面，不得为了美观裁掉信息。
- 合并跨页图时保持阅读顺序，并确认没有重复、缺缝或缩放到不可读。

## 5. 双向视觉验收

对每张最终图片执行：

1. 根据原始 legend 核对其应含的面板范围；
2. 将最终 PNG 与原始 PDF 页面并排查看；
3. 检查标签、图例、坐标、比例尺、统计标记和边缘内容；
4. 从笔记中的 Figure 链接与逐子图 Callout 反查图片；
5. 从 Figure 文件反查笔记，确认没有漏图或孤立图片。
6. 为每张最终图片盘点全部可见文字，记录去向：正文必要解释、共享解释、折叠完整legend/资源表保留或仅内部核验。关键干预、分组和读出必须在教学中讲清；不再要求逐个统计符号、资源编号或构建坐标都有正文教程。高分辨率下仍无法辨认的文字列为异常，不得猜测。

文件存在、链接有效、图像内容完整是三个独立验收项。脚本不能代替逐张视觉核验。

## 取证完整与教学取舍分开

样本量、统计方法、剂量、时间、操作与来源冲突仍须内部核实，不因用户不需要统计课而少读来源。完整legend仍须忠实翻译，但按面板拆分并默认展开地放在对应陪读之前；跨面板共用条件在首个相关面板前完整翻译，统一统计尾注可在相关面板组结束后折叠。正式表仍完整翻译并按需要折叠查阅。教学主线只展开理解当前干预、分组和结果意义所需的信息；常规技术与统计局限集中模块三，不让审计细节打断逐图阅读。

## 6. 最终目录与来源保留

最终目录只允许：

```text
YY.MM.DD-论文中文题目/
├── 设计思路与证据审查.md
├── 课题复现与迁移模板.md
├── Figure/
└── Source/
    ├── 正文.pdf
    └── 补充材料.pdf
```

`Source/` 保存本次实际读取的原始文件内容；归档复制不会改写PDF内部内容，但正文与主补充PDF的文件名必须分别为`正文.pdf`和`补充材料.pdf`。完成前同时核对文件名和文件身份，发现下载串名、`原文.pdf`或把reporting summary误作补充材料均须返工。最终目录不得出现 OCR、渲染页、脚本、日志、台账、缓存或 contact sheet。

完整任务验收须确认两份Markdown均存在且有实质内容；第二份不得以空白模板或核心笔记模块三替代，并须具有基础地图与逐判别单元Callout，能够脱离第一份文件独立阅读。

# 用户最终确认的成稿规则（最高优先级）

## 阅读辅助优先，不是逐图审稿

用户需要提前回答：分组用了什么；干预作用于哪里、原理是什么；作者为什么这样设计；结果说明什么；接着为什么做下一步。详细程度接近导师陪读，不是“完整图注＋统计教程＋批判性结尾”。

干预生物学原理必须按需展开。例如预处理刺激为何能让细胞进入待响应状态、位于细胞表面与进入胞质的刺激为何启动不同路线、支路抑制剂阻断哪一步、阻断后为什么仍可能保留末端读出。仅写“某药预激”而不解释读者所需原理，不合格。

通用技术操作不作教程。Input/IP样品对应、FLAG实际标在谁身上、IgG为何是对照等若决定分组理解，仍要解释；不默认介绍离心、抗体孵育、转膜、载体构建坐标或试剂配制。取舍依据是是否改变当前实验的理解，不是按方法名称一刀切。

## 三模块与阅读节奏

模块一简短导航；模块二主体讲全主图和补图，但主补图必须按科学论证链穿插，禁止先讲完全部主图再统一讲补图。先建立“当前命题—主图证据—直接支撑/排除该命题的补图—下一问题”依赖地图；承重补图紧跟所服务的主图或实验单元，不按图号或PDF边界机械排序。每张Figure内部按“标题—完整图片—`[!info] 本图术语准备`—整图共同前导—A图注译文—A陪读—B图注译文—B陪读……”排列。术语准备在读第一个面板前，用逐条`<small>`预解释整图正文会使用的关键基因/蛋白、细胞、模型、工具药、处理、标记和检测方法缩写；每条讲全称与中文名、基本属性、一般功能/用途及本图角色，并保留原图标签供后文对应。面板各有Callout，但不要求相同栏目、段落数、句首或顺序。禁止逐面板汇总表替代教学，允许必要的局部分组表。

共同干预在前导或首次相关面板讲清，后续可按读者需要回顾，并补足新增问题。用户接受有助于理解的重复，不把去重或压缩篇幅作为主要优化目标。结果可以简述，不逐个读P值、误差线或重复次数。新功能指标要说明测什么、变化意味着什么，不展开统计课或评分量表细则，除非其含义决定结论方向。

完整作者legend不再统一放在整图末尾，而是按面板拆分、默认展开并紧贴对应陪读之前：`[!quote] 作者图注翻译｜Figure XA`之后立即接Figure XA讲解，B、C依次相同。跨面板共同条件在首个相关面板前用一个共用说明完整翻译并标注范围；统一样本量、统计和符号尾注可在相关面板组结束后折叠保留。无法无损拆开的A–B合并句只出现一次并标明A–B，不机械复制。图注保持作者陈述，不混入教学解释；教学讲解不得因就近放置图注而缩短。

常规方法、统计、外推、药理局限集中模块三。图末用一两句说明重要结论边界可以保留；立即防止误解的提醒也可留在相关面板，如“测的是前体而非活性”。这不是必须填满的配额，不要逐面板固定以“不能证明／尚未证明”收尾，也不要先在各面板提醒、再在整图结尾重复同一局限。重点仍是先讲透获得了什么认识，而不是列一串缺失实验。

## 关键名词：解释到能用于读图

展开英文全称或给出中文译名不等于解释完成。首次遇到决定理解的细胞、刺激、标记、对照或检测对象，应按当前需要说明它是什么、在这项实验里承担什么角色，以及为什么用它；不必对所有名词机械回答三问。

例如某类目标细胞不能只给中文译名，还应交代它在相关组织中的角色及为何纳入比较；炎症刺激应解释作者借它模拟什么状态、预计改变哪一步；谱系标记应说明本实验如何借其信号识别目标群体及与另一信号建立关系，不把标记默认说成绝对特异；载体对照应点明它与处理组真正相差什么。示例用于判断解释深度，不是每篇论文必讲的术语清单；具体功能与分组须据来源核实。

检验标准：读者知道中文名称后，是否仍会问“为什么加它／为什么测它／这一组代表什么”？若会，说明解释尚未完成。解释还须减少而不是增加疑问：不能用MyD88、IRAK、TRAF6、NF-κB/MAPK这样的未解释名称串代替作用关系。必要节点用普通语言说明角色；与本图无关的中间节点可概括为胞内传信蛋白，后文真正研究时再展开。即使使用“接头蛋白”“激酶”等词，也要按需要说明其作用，不把读者推入新的查词链。具体生物学关系须核实，简化不能改错机制。

适度重复可帮助记住分组、重建信号关系和衔接前后图，不要求每段都提供全新事实；不要为了精简删掉这些帮助。仍不鼓励机械复制凑字，也不放宽逐面板批判性结尾的限制。

## 硬字数下限与有效内容

- 正式子图有效教学正文至少400个中文字符；
- 整图面板平均至少550个中文字符；
- 共同前导至少350个中文字符，不分摊至面板平均值；
- 干预组合、互作、机制转折、必要性、救援、通路分叉和关键排除等高负荷面板至少700个中文字符。

仅纯标签、单一流程箭头、紧邻代表图且不新增问题的机械定量可记录豁免；一图不超过四分之一面板、不能连续两个、高负荷不得豁免。简单操控确认不自动豁免。

legend、标题、通用操作/统计教程、常规批判、无教学作用的机械重复、固定提示语不计有效字数。帮助当前面板理解的回顾可以计入，不能仅因同一概念前面出现过就扣除；重复不能替代本面板实际结果及其意义。不许取消下限，不许凑字。不足时回到本图尚未解释的干预原理、分组判别和意义补写。

`本图术语准备`同样不计入共同前导或面板字数。它只降低第一次进入Figure的名词门槛，不能承担问题、分组、干预原理、结果或意义。覆盖完整优先于简短：凡后续正文实际使用且新读者可能不认识或不知道用途的科学名称均须收录；关键词多时在同一Callout内按对象/模型、干预/工具、读出/方法分组，不能为控制长度删词。同一术语跨Figure重复出现时允许并鼓励再次解释，至少回顾基本属性和本图角色。缺少术语准备或面板正文出现未预解释的关键科学缩写，当前Figure必须返工。

## 验收以真实理解为准

每个面板分别验收“设计讲通、实际结果讲到、结果意义讲透”，并记录对应正文位置。没有新增干预的观察或定量面板，解释其对象、比较与读出，不编造干预。结果不能只写“支持前述结论”，须点明本面板关键比较及其观察；解释变化为何回答本轮问题。任何一项缺失都必须返工，长篇背景不能抵扣。

内置通用合成样稿强调：干预原理之后必须接实际结果，再解释组织现象如何获得细胞层面的解释、不同读出各意味着什么，以及下一步为何必要。其教学投入是标尺，虚构名称和段落顺序不是模板；严格字数门槛不能被“结果简述”降级。

读完一图应知道：给谁用了什么、改变哪一步、为什么这样比、结果让作者知道什么。关键原理不能只藏在折叠legend中。首次关键术语解释足以继续阅读即可，不追求所有英文全称齐全。

图中文字全部内部核对，但不是全部逐项教学。记录去向：主线必要解释、共享解释、完整legend/资源表保留、仅内部核验。剂量或时间决定急性激活与表达变化的区别时要讲，否则保留查阅。图像完整性与正文讲解取舍是两件事。

作者陈述、图中观察、背景知识和设计逻辑重建保持可区分。未明确交代的动机写“这一设计可以用来区分……”或注明合理重建，不冒充作者原意。即使不写批判段落，结论措辞仍受证据约束。

用户认可的合成机制分叉示例见深度契约：它是干预原理与意义展开程度的标尺，不能复制段落顺序。后续复杂图对比教学行为，不比句式；普通定量图无需同等长度。

## 工作流与成品不变

完整任务必须交付`设计思路与证据审查.md`与`课题复现与迁移模板.md`两份文件，第二份的内容要求见SKILL.md“第二份交付”。内置Figure样稿、核心笔记模块三或临时Figure独立稿均不能替代它。此项恢复不改变既有逐图规则和字数门槛；仅指定单图的任务保持原有范围。

第二份模板必须独立可读：开头用Callout完成不少于800个有效中文字符的基础介绍，只用中文和通俗角色讲清研究背景、对象关系、模型和承重策略；这里不堆英文全称、缩写卡、基因符号或方法名词解释。每个原文实验判别单元固定使用“问题`[!question]`—方法设计`[!example]`—实际结果`[!success]`—意义`[!important]`—下一问题`[!question]`”五类独立Callout。迁移建议也用Callout区分设计、判断分支及前置风险。此版式只适用于第二份模板，不改变第一份逐图笔记的自由叙事规则。

第二份模板中，每个实验判别单元在`问题`前放一个紧凑的`[!info] 本单元术语准备`，用逐条`<small>...</small>`解释该单元会出现的基因/蛋白、细胞、模型、工具药、处理和检测方法缩写。每条必须依次包含：英文全称与中文名、基本名词解释（它属于什么及基本属性）、脱离本文也成立的一般功能/用途、当前单元角色；通常用2—4句或约60—140个中文字符。不能只写文章中的作用，也不能只有译名。覆盖完整优先于长度控制：只要本单元正文会使用且可能影响新读者理解就必须收录；同一关键词在后续单元重复解释没有问题，不能以已在前文出现或术语块过长为由删除。术语说明不散插进五类正文，不计入教学字数。标准单位、统计符号、Figure面板号、引文/登录号、URL与文件扩展名可豁免。此规则只调整第二份模板，不改变第一份逐图笔记的术语排版。

进入具体实验判别单元后必须保留原图标签：术语准备首次绑定缩写与中文名，五类正文随后沿用原图中的基因/蛋白符号、细胞系、模型、工具药和方法简称，不得将`ColVI`等标签全篇替换为“Ⅵ型胶原”等纯中文表达，也不得自创同义缩写。第一次可写“`ColVI`（Ⅵ型胶原）”，后文以`ColVI`为主，确保正文能直接对应原图及其阳性比例/比值公式。原文命名若不一致则明示差异，不能静默规范化。基础地图仍优先用中文，不受此条限制。

第二份模板的致命验收点是研究路线引导深度。每个常规实验判别单元五类正文合计至少900个有效中文字符，高负荷单元至少1300个；术语准备、链接、legend、统计教程、操作SOP和常规批判不计数。常规单元的`方法设计/实际结果/意义`分别至少280/200/260个有效中文字符，高负荷单元至少400/280/380个。问题必须写出前一步留下的竞争解释；方法必须讲对象、共有条件与变量、关键对照、干预原理、读出含义、决定性比较及其判别力；结果必须给出真实方向、阴性或残留结果；意义必须说明排除/保留了什么解释、证据推进到哪一层及本单元在全篇路线中的作用；下一问题必须点明具体缺口与下一步怎样补。简单机械确认应合并到相邻单元，不能用大量薄单元制造“完整”假象。

全量读取后先制作主图—补图依赖地图，再按逻辑顺序严格串行启动独立Figure或跨图实验单元子任务，主任务逐项验收；下一项可以是Figure S，禁止默认主图全部完成后才处理补图。最终拼接继续按该逻辑顺序，不能重新按主图/补图分类。指定单图完成后停止。图片完整、正式表完整翻译、来源留存、三模块和Figure/Source目录不变。`Source/`中经内容核实的主论文PDF必须命名为`正文.pdf`，Supporting Information主PDF必须命名为`补充材料.pdf`；不得保留下载串名或使用`原文.pdf`，也不得把reporting summary等附件冒充补充材料。不得借教学重心调整省略取证或主补图。
